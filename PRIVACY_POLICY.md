# Privacy Policy

Last Updated: June 2026

EZ AutoRefresh respects your privacy.

## Information Collection

EZ AutoRefresh does not collect, store, transmit, or share any personally identifiable information.

The extension does not:

* Track browsing history
* Collect personal information
* Collect passwords or authentication data
* Monitor user activity
* Send data to external servers
* Use analytics or tracking services

## Local Storage

The extension stores refresh task settings locally using Chrome Storage API.

Stored data may include:

* Tab identifiers
* Page URLs
* Refresh mode settings
* Refresh intervals
* Task scheduling information

This data remains on the user's device and is used solely for providing the extension's functionality.

## Data Sharing

EZ AutoRefresh does not sell, transfer, share, or disclose user data to any third party.

## Remote Code

EZ AutoRefresh does not download or execute remote code.

All extension functionality is packaged within the extension itself.

## Security

All data is stored locally within the browser's extension storage area.

No external network communication is performed by the extension.

## Changes to This Policy

This Privacy Policy may be updated from time to time. Any changes will be reflected on this page.

## Contact

If you have questions regarding this Privacy Policy, please contact the extension developer through the Chrome Web Store support page.
