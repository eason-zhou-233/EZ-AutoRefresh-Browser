# EZ AutoRefresh 页面刷新工具

EZ AutoRefresh 是一款轻量级、高可靠性的 Chrome 自动刷新插件，支持固定时间刷新和随机时间刷新，适用于监控页面、工单系统、运营后台、数据看板等需要持续更新内容的网页。

## 功能特性

* 固定时间自动刷新
* 随机时间自动刷新
* 多标签页任务管理
* 实时倒计时显示
* 在线编辑运行中的任务
* 单独停止任务
* 一键停止全部任务
* 浏览器重启后自动恢复任务
* 基于 Chrome Manifest V3 开发
* 轻量、安全、无广告

## 安装方式

### Chrome 应用商店安装

在 Chrome Web Store 搜索并安装 EZ AutoRefresh。

### 手动安装

1. 下载项目源码。

2. 打开 Chrome：

   chrome://extensions/

3. 开启开发者模式。

4. 点击“加载已解压的扩展程序”。

5. 选择项目目录。

## 使用说明

### 启动自动刷新

1. 打开需要刷新的网页。
2. 点击浏览器工具栏中的 EZ AutoRefresh 图标。
3. 选择刷新模式：

* 固定时间
* 随机时间范围

4. 设置刷新时间。
5. 点击“启动当前页面刷新”。

### 任务管理

任务列表中会显示：

* 当前运行状态
* 剩余倒计时
* 下次刷新时间
* 刷新模式和时间配置

支持：

* 编辑任务配置
* 停止单个任务
* 停止全部任务

## 权限说明

### tabs

用于刷新指定标签页。

### alarms

用于创建定时刷新任务。

### storage

用于保存任务配置，并在浏览器重启后恢复任务。

## 隐私说明

EZ AutoRefresh 不会收集、存储、上传或共享任何个人信息。

所有任务配置仅保存在用户本地浏览器存储中。

插件不会向任何第三方服务器发送数据。

详细内容请参阅《隐私政策》。
